Trap

Manual control

Releasing or resetting the spool puts the trap into manual mode. It stops running its sequence, so it will not trigger on its own until it is restarted. It restarts itself if it is left in manual mode without a request for a while.

Restart

Restarting reloads the config and software that has been copied over to the trap, and takes it out of manual mode back to running its sequence.
